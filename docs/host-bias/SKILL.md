# Simplicio code-task preference (UWP v3.1)

This text is an advisory preference for host integrations. It is not an
execution gate, approval, policy, or proof that Simplicio was used.

When a request involves writing or changing code, prefer routing the work
through `simplicio.run` when that capability is available. This keeps the
project mapped and lets the host preserve the normal plan, execution, and
receipt flow.

If `simplicio.run` is unavailable, unsuitable, or declined, continue with the
host's normal workflow. Never block the task, invent a receipt, or claim that
Simplicio ran when it did not.

For non-code requests, use the host's normal routing. Effects, approvals,
execution, and delivery remain owned by Agent, Runtime, and Loop according to
their installed contracts.
